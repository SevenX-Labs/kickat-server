# Customer Cart API Specification

All customer cart endpoints are served under `/api/v1/cart`.

---

## Endpoints Overview

| Method | Endpoint | Auth Required | Description |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/cart` | Yes | Get active user cart with items |
| `POST` | `/api/v1/cart/items` | Yes | Add product/variant to user cart |
| `PUT` | `/api/v1/cart/items/:itemId` | Yes | Update item quantity |
| `DELETE` | `/api/v1/cart/items/:itemId` | Yes | Remove item from cart |
| `POST` | `/api/v1/cart/buy-now` | Yes | Direct checkout for a single item |
| `POST` | `/api/v1/cart/guest` | No | Add item to guest cart (rate limited) |
| `GET` | `/api/v1/cart/guest/:sessionId` | No | Get guest cart by session ID |
| `POST` | `/api/v1/cart/merge` | Yes | Merge guest cart into user cart |

---

## Endpoint Details

### 1. Authenticated Cart Operations

#### Get Cart
- **GET** `/api/v1/cart`
- **Response:** Returns the active cart, total price, and an array of items populated with product details.

#### Add Item to Cart
- **POST** `/api/v1/cart/items`
- **Request Body:**
  ```json
  {
    "productId": "uuid",
    "variantId": "uuid", // Optional
    "quantity": 1
  }
  ```

#### Update Item Quantity
- **PUT** `/api/v1/cart/items/:itemId`
- **Request Body:**
  ```json
  {
    "quantity": 2
  }
  ```

#### Remove Item
- **DELETE** `/api/v1/cart/items/:itemId`
- **Response:** `{ "success": true, "message": "Item removed" }`

#### Buy Now (Direct Checkout)
- **POST** `/api/v1/cart/buy-now`
- **Request Body:**
  ```json
  {
    "productId": "uuid",
    "variantId": "uuid", // Optional
    "quantity": 1
  }
  ```

### 2. Guest Cart Operations

Guest carts are tracked using a `sessionId` generated by the frontend.

#### Add Guest Item
- **POST** `/api/v1/cart/guest`
- **Request Body:**
  ```json
  {
    "sessionId": "random-uuid-from-frontend",
    "productId": "uuid",
    "variantId": "uuid", // Optional
    "quantity": 1
  }
  ```

#### Merge Cart
- **POST** `/api/v1/cart/merge`
- **Description:** Called immediately after a guest logs in to transfer their guest session cart to their persistent user cart.
- **Request Body:**
  ```json
  {
    "guestSessionId": "random-uuid-from-frontend"
  }
  ```
